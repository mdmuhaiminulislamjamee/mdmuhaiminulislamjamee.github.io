Projects

Ten project entries from a portfolio spanning embedded systems, robotics, IoT, computer vision, and artificial intelligence.

Project 01

Four-Storey Elevator Control System

A dual-Arduino elevator controller using an I²C master–slave architecture and the SCAN scheduling algorithm. The system coordinates motors, displays, request handling, door control, obstacle detection, overload protection, and manual safety overrides.

Skills:
  • Arduino
  • I²C
  • Control
  • Embedded C
  • Safety Systems
Project 02

Autonomous Garbage Detection & Collection Robot

An autonomous robot that combines deep-learning detection with SLAM, LiDAR and sonar sensing, Kalman filtering, and A* path planning to locate, approach, collect, and store waste in real time.

Skills:
  • SLAM
  • YOLO
  • Fast R-CNN
  • Raspberry Pi
  • A*
Project 03

Land Mine & Human Detection Robot

An IoT-enabled safety robot combining GPS, GSM, environmental and metal sensors, image processing, and live video to detect hazards, identify human presence, and transmit alerts with coordinates.

Skills:
  • IoT
  • GPS/GSM
  • ESP32-CAM
  • Image Processing
  • Telemetry
Project 04

Autonomous Self-Driving Car with Text Translation

A ROS and computer-vision vehicle that performs lane and object detection, localization, route planning, and English–Bangla road-text translation using a Raspberry Pi camera platform.

Skills:
  • ROS
  • Computer Vision
  • YOLO
  • Kalman Filter
  • Dijkstra
Project 05

PID-Controlled Fast Line-Following Robot

A high-speed robot built around a six-sensor infrared array, Arduino Nano, custom PCB, and L298N motor driver. Dynamic PID correction minimizes path deviation while preserving speed and stability.

Skills:
  • PID
  • Arduino Nano
  • Custom PCB
  • IR Sensors
  • Motor Control
Project 06

Human-Rescue & Fire-Fighting Robot

An emergency-response robot using IoT, environmental and infrared sensing, and image processing to navigate hazardous spaces, detect fire and trapped people, and transmit live situational data to operators.

Skills:
  • IoT
  • Thermal Sensing
  • Computer Vision
  • Remote Monitoring
  • Robotics
Project 07

AI-Based Smart Notice Board

A personalized notice-delivery platform that recognizes users with facial recognition, retrieves relevant information through a server and database, and displays tailored updates through a web interface.

Skills:
  • Facial Recognition
  • Python
  • Node.js
  • MySQL
  • WebSockets
