Project 01

Four-Storey Elevator Control System

This project is the design and implementation of a smart four-floor elevator system using dual Arduino Uno microcontrollers with an I²C-based master–slave architecture, where the master handles decision-making and user interaction while the slave manages hardware control and safety monitoring. The system operates using the SCAN (Elevator) algorithm to efficiently serve floor requests in a structured direction-based manner, minimizing travel time and ensuring fairness. It integrates multiple hardware components including DC and servo motors, dual LCD displays, ultrasonic and force sensors, and a 7-segment indicator to provide real-time feedback and smooth operation. Advanced features such as synchronized door control, obstacle detection, overload protection, manual override buttons, and external call inputs enhance both usability and safety. The design emphasizes reliability, modularity, and real-world applicability, with independent safety mechanisms ensuring immediate response to hazards. Overall, the project demonstrates a practical, scalable, and intelligent elevator control system that closely mimics real-world elevator behavior while addressing key engineering challenges.

Project 02

Autonomous Self-Driving based Garbage Detection and Collection Robot using Deep Learning and Simultaneous Localization & Mapping

This project presents an Autonomous Self-Driving Garbage Detection and Collection Robot that uses Deep Learning and Simultaneous Localization & Mapping (SLAM) for real-time trash detection and navigation. The system is powered by a Raspberry Pi with a Pi Camera for image capture, integrated with Fast R-CNN and YOLO models to identify waste objects. Different sensors like LiDAR sensor, Sonar Sensor are used for mapping and obstacle detection, while Kalman Filter and A* Algorithm guide smooth path planning and localization. The robot’s motion and trash collection mechanisms are controlled by Servo Motors and an Arduino Mega connected via the I2C protocol. In simple terms, the robot scans its surroundings, detects garbage, plans a safe shortest route, moves towards the trash, picks it up, and deposits it into its storage compartment—all autonomously.

Autonomous Self-Driving Car with Text Translation

This project is an Autonomous Self-Driving Car with Text Translation that combines ROS and Computer Vision for intelligent navigation and language assistance. Powered by a Raspberry Pi and Pi Camera, the car performs real-time lane detection and object recognition using YOLO models. Project 05

Custom Real-Time Hand Gesture Recognition System for Edge AI Devices

This project features a real-time, 8-command hand gesture recognition system developed by training an augmented 128–64 MLP architecture on 36,864 samples across 9 classes utilizing a 76-dimensional landmark feature extractor. To maximize reliability, the pipeline incorporates runtime rejection, temporal gesture gating, and a geometry-based dorsal fallback, correctly recognizing 100% (331/331) of dorsal public-test samples. Evaluated on 3,631 public-test observations, the system substantially outperforms the 92.9% baseline by achieving a 98.8% known-command acceptance rate, a 99.0% runtime macro-F1 score, and a 0.4% unknown false-accept rate, fully optimized for low-latency live camera evaluation via ONNX inference.

Project 09

Real-time CNN on Drones with IoT Integration for Smart Border Surveillance.

TThis project presents the design and implementation of a drone-based smart border surveillance system that integrates Convolutional Neural Networks (CNN), computer vision, GPS, and IoT technologies for real-time monitoring and classification of individuals in restricted border areas. A custom dataset of 3,256 images, comprising 1,984 border-guard and 1,272 local-person samples, was developed using data augmentation techniques including rotation, scaling, and flipping. The CNN model processes 100×100-pixel grayscale images using two convolutional layers with 200 and 100 filters, 2×2 max-pooling, 50-neuron fully connected layers, 0.5 dropout, ReLU and softmax activations, and is trained with the Adam optimizer, categorical cross-entropy loss, a 0.0001 learning rate, 32 batch size, and 10 epochs with early stopping. The drone integrates an Arduino Mega, ESP32-CAM, NEO-6M GPS, SIM900 GSM, BME280, HMC5883L, MPU6050, nRF24L01+, and brushless motor with ESC, enabling aerial image acquisition, environmental sensing, location tracking, wireless communication, and real-time data transmission through ThingSpeak. Experimental evaluation achieved 98% overall accuracy, with 98% precision, 98% recall, and 98% F1-score for border-guard classification and 98% precision, 97% recall, and 97% F1-score for local-person classification. The system further supports timestamped location reporting and authority notification for detected individuals, demonstrating a practical IoT-enabled computer vision framework for automated border-area monitoring and surveillance.

Project 10

mprovement of Image Quality of Received Holographic Image Using Advanced Fresnel Algorithm

This project focuses on enhancing the quality and security of received holographic images using an advanced Fresnel Fourier algorithm for computer-generated holography (CGH). The system implements a complete holographic communication pipeline involving grayscale conversion, hologram generation, complex reference-wave integration, magnitude–phase separation, multiplexing, demultiplexing, and Fresnel-based image reconstruction using FT, DFT, and IDFT techniques. A 256×256-pixel, 8-bit image was employed for experimental evaluation, with the Fresnel diffraction method validated across propagation distances of 0.1–0.7 m and operating wavelengths ranging from 350–470 nm. The proposed approach incorporates a reference noise image and binary hologram encoding to improve communication security while mitigating image artifacts such as ringing, blurring, and improper diffraction. Experimental analysis demonstrated optimal reconstruction behavior at Fresnel distances of 7–12 cm, while distances of 1 cm and 0.1 cm produced progressively higher distortion and blurring. Wavelength analysis further showed improved sharpness at 350/470 nm and enhanced contrast and intensity transitions at 630/700 nm, whereas wavelengths around 1500 nm resulted in invisible reconstructions. Performance was quantitatively evaluated through RGB color-space, histogram, correlation-coefficient, and information-entropy analyses, with the main object image achieving an entropy of 6.5326, while the generated hologram reached 7.9530, the multiplexed hologram 7.9895, and the reconstructed image 6.4884. The system successfully reconstructed both grayscale and color images with improved contrast, brightness, and sharpness, demonstrating the practical potential of advanced Fresnel diffraction and FCGH techniques for secure, high-fidelity holographic communication.

Skills:
  • Computer-Generated Holography (CGH)
  • Fourier Optics & Wave Diffraction
  • Digital Signal & Image Processing (DFT/IDFT)
  • Optical Cryptography & Steganography
