How to Make a Simple LED Project with Arduino

15 September 2026

Blinking an LED is a small project, but it teaches the complete workflow used in larger embedded and robotics systems: build a circuit, configure a pin, upload a program, observe the result, and improve the behavior.

What you need

  • Arduino Uno or a compatible board
  • One LED
  • One 220 Ω or 330 Ω resistor
  • Breadboard and jumper wires
  • USB cable and the Arduino IDE

Connect the circuit

  1. Disconnect USB power while building the circuit.
  2. Connect Arduino digital pin 8 to one end of the resistor.
  3. Connect the other end of the resistor to the LED’s longer leg, called the anode.
  4. Connect the LED’s shorter leg, called the cathode, to an Arduino GND pin.
  5. Check the LED direction and connections, then reconnect the USB cable.

The resistor limits current and protects both the LED and the Arduino output pin. Do not connect an external LED directly between pin 8 and ground without a resistor.

Upload your first program

const int ledPin = 8;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

How the code works

The setup function runs once and configures pin 8 as an output. The loop function runs repeatedly. HIGH applies voltage to the LED circuit, LOW removes it, and delay pauses the program for a number of milliseconds. A delay of 1000 means one second.

Try a faster blink

Change both delay values to 200 and upload the sketch again. The LED will blink five times faster.

digitalWrite(ledPin, HIGH);
delay(200);
digitalWrite(ledPin, LOW);
delay(200);

Troubleshooting

  • If the LED does not light, rotate it because LEDs work in only one direction.
  • Confirm that the correct board and serial port are selected in the Arduino IDE.
  • Check that pin 8 in the circuit matches ledPin in the program.
  • Make sure the jumper connected to the short LED leg reaches GND.

You have now controlled a physical component with software. The same idea scales to buzzers, relays, motors, displays, and complete robots.
