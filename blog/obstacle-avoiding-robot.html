Run Your First Obstacle-Avoiding Robot

03 May 2026

An obstacle-avoiding robot is an excellent first autonomous system. An ultrasonic sensor measures the distance ahead, the Arduino decides whether the path is clear, and a motor driver controls the two drive motors.

Components

  • Arduino Uno or compatible board
  • HC-SR04 ultrasonic sensor
  • L298N motor-driver module
  • Two geared DC motors, wheels, and a caster wheel
  • Robot chassis
  • Battery pack suitable for the motors
  • Jumper wires and a common ground connection

Circuit connections

  • HC-SR04 VCC to Arduino 5V, GND to GND, Trig to pin 9, and Echo to pin 10.
  • L298N IN1, IN2, IN3, and IN4 to Arduino pins 2, 3, 4, and 5.
  • Connect the left and right motors to the L298N output terminals.
  • Connect the motor battery to the L298N power input according to the module and motor ratings.
  • Connect Arduino GND, sensor GND, and motor-driver GND together. Never power the motors directly from an Arduino I/O pin.

How the robot decides

  1. Send a short ultrasonic pulse.
  2. Measure how long the echo takes to return.
  3. Convert the travel time into distance.
  4. Drive forward when the distance is greater than the safety threshold.
  5. Stop, reverse briefly, and turn when an obstacle is too close.

Arduino code

const int trigPin = 9;
const int echoPin = 10;
const int in1 = 2;
const int in2 = 3;
const int in3 = 4;
const int in4 = 5;

long distanceCm() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH, 30000);
  if (duration == 0) return 400;
  return duration * 0.034 / 2;
}

void forward() {
  digitalWrite(in1, HIGH); digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH); digitalWrite(in4, LOW);
}

void reverseRobot() {
  digitalWrite(in1, LOW); digitalWrite(in2, HIGH);
  digitalWrite(in3, LOW); digitalWrite(in4, HIGH);
}

void turnRight() {
  digitalWrite(in1, HIGH); digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);  digitalWrite(in4, HIGH);
}

void stopRobot() {
  digitalWrite(in1, LOW); digitalWrite(in2, LOW);
  digitalWrite(in3, LOW); digitalWrite(in4, LOW);
}

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(in1, OUTPUT); pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT); pinMode(in4, OUTPUT);
}

void loop() {
  if (distanceCm() > 20) {
    forward();
  } else {
    stopRobot();
    delay(150);
    reverseRobot();
    delay(350);
    turnRight();
    delay(450);
  }
}

Test safely

  • Lift the wheels off the ground for the first motor-direction test.
  • If one wheel spins backward, swap that motor’s two output wires.
  • Place the robot on a clear floor and begin with a low motor voltage.
  • Adjust the 20 cm threshold and turning delay for the robot’s speed and chassis.
  • Keep wires away from wheels and disconnect the battery before changing connections.

This program uses a simple fixed right turn. A later version can mount the sensor on a servo, compare open space on both sides, add speed control with PWM, or use additional sensors for smoother navigation.
