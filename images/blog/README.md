# Blog image uploads

On GitHub, select **Add file → Upload files**, upload the correctly renamed `.jpg` file, and commit to `master`.

| Filename | Used on |
| --- | --- |
| `what-is-a-robot.avif` | “What Is a Robot?” listing thumbnail and article image |
| `simple-led-project-arduino.jpg` | Arduino LED listing thumbnail and article image |
| `obstacle-avoiding-robot.avif` | Obstacle-avoiding robot listing thumbnail and article image |

A clear landscape project photograph works best. The same image appears as a square-cropped blog thumbnail and a wide article cover.
